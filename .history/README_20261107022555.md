# Sri Lanka Destination Explorer

A full-stack web application that allows visitors to explore popular tourist destinations in Sri Lanka and view their current weather conditions.

## Project Overview

Sri Lanka Destination Explorer provides a public website for browsing destinations and an admin dashboard for managing destination information.

## Technologies Used

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- NestJS
- TypeScript
- RESTful APIs

### Database
- MongoDB
- Mongoose

### External API
- Open-Meteo Weather API

### Deployment
- Railway

### Version Control
- Git
- GitHub

## Main Features

### Public Website
- Browse available destinations.
- View destination details.
- View destination images.
- Check current weather conditions.
- Access without authentication.

### Admin Dashboard
- Admin login and logout.
- Add destinations.
- View destinations.
- Edit destination details.
- Delete destinations.

## Destination Information

Each destination contains:
- Name
- Description
- Latitude
- Longitude
- Image URL
